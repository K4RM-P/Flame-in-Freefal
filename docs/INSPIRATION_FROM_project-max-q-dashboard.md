## Summary

Project Max Q ("Flame Firewall") is a single-page static dashboard. It has six curated ISS combustion study cards (BASS-II, Saffire-I, Saffire-IV/V, SAME, SAME-R and FLEX), keyword-ranked evidence retrieval and a chat-style research assistant called "Aster". Around these sit a small physics lab (Burke–Schumann flame sheet, a two-stage FLEX d² reconstruction, scalar dissipation and Damköhler sliders) and a "Simulation Bay". The Simulation Bay is a canvas 3D cabin where Monte Carlo smoke particles drift with airflow, mixing and gravitational settling to a detector. It includes paired detector-placement trials, a rack-obstruction flow map and a placement scan. **Stack:** hand-written vanilla JS, HTML and CSS in `dist/` with no build step and no tests. An optional Cloudflare-style worker (`worker/index.mjs`, bundled by `worker/build.mjs`) serves the assets and calls the OpenAI Responses API (`gpt-4.1-mini`) with a JSON-schema output. In the browser it can also use Chrome's on-device `LanguageModel`.

## Top 5 ideas worth adopting later (ranked by points per hour, NOT implemented)

1. **Add real NASA imagery to the landing and Methods pages.** (S, Presentation.) The landing page says "No NASA imagery is embedded yet". Download the public-domain SoFIE gallery image and a 1 g vs µg candle comparison **directly from nasa.gov** (do not copy OTHER's files). Place them in `web/public/images/`, add an entry for each to `CREDITS.md`, and show them in the hero and the "problem" block of `web/app/page.tsx` and in `web/app/methods/page.tsx`. Use `next/image` with explicit sizes and alt text. Add an e2e assertion in `web/e2e/` that the images load. The one-frame "flame shape changes without gravity" visual lifts Presentation for little effort.

2. **Add gravitational settling velocity to the smoke module.** (S, Validity + Impact.) `physics/emberphys/smoke.py` already computes the Cunningham slip C_c from the mean free path at habitat T and P. Add an `SM4` equation, v_s = ρ_p g d² C_c / (18 μ), as a `settling()` function returning a `ModelResult`. Read ρ_p from `physics/data/properties.yaml` (with a source, or `TODO_VERIFY`) and take g from the mission. Port it to `web/lib/physics/smoke.ts`, add golden vectors (`make vectors`) and a pytest case for the Stokes limit. Then show "settling over the source–detector distance vs transport time" on the smoke card in the Console. Unlike OTHER, this must use pressure-dependent λ and μ(T) rather than sea-level constants, which matters at 8.2 psia.

3. **Add a "what changed" diff to the Evidence compare view.** (S, Validity + Presentation.) In `web/app/evidence/page.tsx`, when two test points or investigations are compared, list only the conditions that differ (O₂, P, flow, thickness, g), each with units and a receipt. If exactly one variable differs, mark the pair as a "minimal pair". The data comes from `web/lib/testPoints.ts`. Add a vitest case for the diff helper in `web/tests/`. It shows judges that the physics is read from controlled comparisons.

4. **Digitize the Saffire sample-level rows from NTRS 20210011521 (Table 2).** (M, Validity + Relevance.) `/gaps` currently says "solids await digitization". Transcribe Table 2 **from the NASA paper itself** into `physics/data/digitized/` with a page/table locator for each row. Run it through `physics/pipeline` with `verified` and `split` flags, and add the rows to the `/gaps` coverage heatmap and to the spread or flame-size validation in `physics/validate` and the Validation Lab. Never fit on `split=="test"`. Saffire fabrics (SIBAL, cotton) are exactly the cabin fabrics Maya signs off, so this gives her a validated solid-fuel point.

5. **Add a 1-D smoke transport time to the detector.** (M, Impact + Creativity.) Create `physics/emberphys/transport.py`: an advection–diffusion first-passage model giving Pe = uL/D_t, the peak (mode) crossing time and the mean L/u (with "no finite mean" at u = 0). Cite Redner, *A Guide to First-Passage Processes*, as OTHER did. The eddy diffusivity D_t goes in `properties.yaml` as a **range** with a source, and its p05–p95 spread feeds `uq.py`. The result is "time for smoke to reach a detector L m away" with uncertainty. Port it to `web/lib/physics/`, add golden vectors and add a card to the Console detection pillar. Combine it with idea 2 to answer "is the smoke still airborne when it arrives?". Skip OTHER's 3D canvas and rack wake model.

## Things OTHER does worse, or that are scientifically risky (avoid)

- **Hard-coded physical constants in UI code.** Examples: Richardson number with fixed ΔT = 30 K, L = 0.1 m and T = 293 K; settling with ρ_p = 1000 kg/m³, μ = 1.81e-5 Pa·s and λ = 66 nm (sea-level air, wrong at 57 kPa); D = 2e-5 m²/s; eddy mixing of 0.012 m²/s. EmberAtlas reads every value from sourced YAML.
- **No uncertainty, no validity envelope and no tests.** Numbers show as point values with 2–4 decimals. There is no extrapolation warning and no unit or golden-vector tests.
- **Hand-tuned relevance scores shown as "pts".** The per-mission `fit` arrays (for example `[20,14,14,18]`) are judgment calls presented as computed scores.
- **Scripted answers.** `lunarSmokeTest` and the "first arrival" text are canned replies triggered by exact question strings. This breaks "AI answers only from tool outputs" and could be read as fake output.
- **A weak AI guard.** The OpenAI path checks only that cited IDs exist. It does not check that numbers in the answer appear in the evidence. The on-device draft has no guard at all. EmberAtlas's `guard.ts` rejects untraceable numbers.
- **Free-parameter toys.** The Damköhler slider uses a user-chosen chemical time, so any Da is possible. The rack wake field and 3D particle cloud look like CFD but rest on no validation data.
- **Guided tour and demo button.** These conflict with EmberAtlas's "No guided tours, no fake data" rule.
- **Built output committed as source** (`dist/`), and a worker that base64-inlines every asset, including fonts and JPGs, into one script.
- **Few studies.** It has 6 studies against EmberAtlas's ~24 investigations, and no partial-gravity bounding beyond caveat sentences.
